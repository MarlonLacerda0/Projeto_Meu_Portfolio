# Portfólio | Marlon Lacerda

Portfólio pessoal que apresenta minha trajetória, conhecimentos e projetos em desenvolvimento de software. Reúne experiências com aplicações .NET, análise de sistemas e desenvolvimento assistido por inteligência artificial.

**Acesse:** [marlonlacerda0.github.io/portfolio](https://marlonlacerda0.github.io/portfolio/)

## Projetos em destaque

- [Training System](https://github.com/MarlonLacerda0/training-system): aplicação para criação e gerenciamento de planos de treino, desenvolvida com apoio do v0.dev, Next.js, TypeScript e Supabase.
- [Escola API](https://github.com/MarlonLacerda0/Escola-api): projeto de estudo em desenvolvimento com ASP.NET Core, Clean Architecture e Repository Pattern.
- [Jogo de Xadrez](https://github.com/MarlonLacerda0/JogoXadrez): jogo de console em C# com foco em programação orientada a objetos.
- [Cadastro de Contatos](https://github.com/MarlonLacerda0/SistemaCadastroDeContatos): aplicação web de cadastro de contatos com ASP.NET.

## Sobre o site

O portfólio é uma página estática construída com HTML e CSS, adaptada para diferentes tamanhos de tela e publicada no GitHub Pages. Para executá-lo localmente, basta abrir o arquivo `index.html` em um navegador.
